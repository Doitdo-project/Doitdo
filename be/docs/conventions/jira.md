# JIRA Convention

노션 SSOT: <https://www.notion.so/3448ab5fe9a980ff9da9ff5bc5094ec4>

## 1. 일감 종류

| 단위 | 의미 |
|---|---|
| Epic | 도메인 단위 |
| Story | 사용자 가치 (서술형: "사용자는 ~ 하고 싶다") |
| Task | 기술 / 관리 업무 |
| Sub-Task | API 단위 (또는 커밋 단위) |

## 2. 작업 제목

서두에 파트 prefix 필수:

`[BE]`, `[FE]`, `[DOCS]`, `[INFRA]`, `[AI]`, `[DB]`

예: `[BE] TODO 카테고리 CRUD API 구현`

## 3. 도메인 구분 — 트리거 기준

행동의 **트리거가 어느 도메인에서 발생하는지**로 일감 도메인을 정한다.

> 예: 다마고치 성장은 TODO 완료가 트리거 → `[BE] TODO ...`

## 4. 도메인 담당

| 도메인 | 담당 |
|---|---|
| 인증 / 유저 | 황예찬 |
| 다마고치 | 전상훈 |
| TODO | 김재환 |

## 5. 스토리 포인트 (피보나치)

기본 사용 값: 1, 2, 3, 5, 8.

| SP | 의미 |
|---|---|
| 1 | 매우 단순 |
| 2 | 단순 |
| 3 | 명확 |
| 5 | 표준 |
| 8 | 고난도 |
| 9 | 대규모 |
| 10 | 매우 위험 |

큰 일감은 분할 권장.
