## 2. 자세한 설명 (Long Description)

**제한**: 1000자 이상 4000자 이하 — 아래 본문 1,481자 (공백 제외 1,018자)

```
매일의 성취가 캐릭터의 성장이 되는 펫 투두 앱

오늘의 할 일을 미루는 이유는 사실 간단합니다. 끝낸다고 해서 즉각적인 보상이 없기 때문입니다.

Doitdo 는 투두 앱에 펫 캐릭터를 더해 매일의 성취가 캐릭터의 성장으로 이어지게 만들었습니다. 단순한 체크박스 대신, 매일 한 가지 일을 끝낼 때마다 알에서 깨어난 슬라임이 애기 슬라임 → 슬라임 → 성체까지 4단계로 자랍니다. 그리고 성체에 도달한 캐릭터는 결국 사용자 곁을 떠나 독립합니다. 그 순간이 도감에 추억으로 기록되고, 새로운 슬라임이 알과 함께 다시 찾아옵니다.

■ 투두 관리

  • 일반 / 반복 / 기간 투두 모두 지원
  • 카테고리 직접 추가 (학습, 업무, 운동, 생활 등 — 최대 6개)
  • 우선순위, 알림 시간, 시작·종료일 세부 설정
  • 스와이프로 완료, 카드형 직관 UI
  • 못 끝낸 일은 "내일로 미루기" 한 번으로
  • 캘린더 뷰 / 키워드 검색

■ 픽셀 펫 성장

  • 4단계 자동 진화 — 알 → 애기 슬라임 → 슬라임 → 성체
  • 카테고리별 꾸밈 아이템 (학습 카테고리 완료 → 연필 + 안경, 업무 → 서류가방)
  • 가상 재화 "두레딧" 으로 상점에서 아이템 구매 — 실제 결제 없음, 투두 완료로만 획득
  • 부화 / 진화 / 이별마다 푸시 알림으로 순간을 놓치지 않게

■ 도감과 이별

  • 성체에 도달한 캐릭터는 사용자의 승인 후 독립
  • 함께한 캐릭터는 도감에 영구히 기록 — 종류별 해금 시스템
  • 새 캐릭터는 랜덤 배정. 이번엔 어떤 슬라임이 찾아올지

■ 알림과 위젯

  • 투두 마감 리마인드, 캐릭터 성장·이별 푸시
  • 방해금지 시간 설정으로 새벽엔 조용히
  • iOS 홈 화면 위젯 — 앱 켜지 않고도 오늘의 투두 + 캐릭터 상태 확인

■ 통계와 스트릭

  • 연속 완료 일수(스트릭) — 매일의 작은 습관이 쌓이는 게 보입니다
  • 카테고리별 완료 통계

■ Doitdo 가 다른 이유

대부분의 투두 앱은 "할 일을 적어두는 도구" 입니다. Doitdo 는 거기에 정서적 보상을 더했습니다. 캐릭터의 성장은 단순한 게이미피케이션이 아닙니다 — 함께 시간을 보낸 슬라임이 결국 떠난다는 "이별" 의 순간이 다음 날의 동기를 만듭니다.

■ 안심하고 사용하세요

  • 광고 없음 — 집중을 방해하지 않습니다
  • 분석·추적 SDK 사용 안 함 — 앱 사용 패턴을 외부로 보내지 않습니다
  • 만 14세 이상부터 이용 가능
  • 회원 탈퇴 시 모든 데이터 즉시 삭제

■ 이런 분께 추천합니다

  • 일정관리 앱이 지루해서 자꾸 안 쓰게 되는 분
  • 매일의 작은 성취에 보상이 있었으면 하는 학생·직장인
  • 펫, 픽셀 아트, 슬라임 캐릭터를 좋아하는 분
  • 게임 같은 동기부여로 습관을 만들고 싶은 분

오늘 한 가지를 끝내고, 슬라임을 만나보세요.
그리고 그 작은 성취가 도감에 추억으로 남는 순간을 경험해보세요.

— Doitdo 팀 드림
```
