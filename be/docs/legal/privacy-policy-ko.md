**{{운영자명}}**(이하 "회사")은 「개인정보보호법」 및 「정보통신망 이용촉진 및 정보보호 등에 관한 법률」에 따라 이용자의 개인정보를 보호하고 이와 관련한 고충을 신속하고 원활하게 처리하기 위하여 다음과 같이 개인정보처리방침을 수립·공개합니다.

## 제1조 개인정보의 수집 항목 및 수집 방법

### 1. 수집 항목

회사는 서비스 제공을 위해 아래와 같은 개인정보를 수집합니다.

| 수집 항목 | 수집 시점 | 필수/선택 | 수집 목적 |
|---|---|---|---|
| 이메일 주소 | 일반 회원가입 / 소셜 로그인(OAuth) | 필수 | 계정 식별 및 로그인 |
| 비밀번호(BCrypt 단방향 해시) | 일반 회원가입 | 필수(일반 가입) / 소셜 가입 시 미수집 | 본인 인증 |
| 사용자명(닉네임) | 회원가입 | 필수 | 프로필 표시 |
| 생년월일 | 가입 후 온보딩 단계 | 필수 | 만 14세 이상 연령 검증 |
| 소셜 제공자 식별자(provider_uid) | 소셜 로그인(Google/카카오/Apple) | 소셜 가입 필수 | 소셜 계정 연동 및 인증 |
| FCM 디바이스 토큰 + 플랫폼(ANDROID/IOS) | 알림 동의 시 | 선택 | 푸시 알림 발송 |
| 약관 동의 시점·버전 | 가입 후 온보딩 단계 | 필수(이용약관·개인정보처리방침) / 선택(마케팅) | 동의 이력 입증 |
| TODO 내용·카테고리·알림 시간 | 서비스 이용 중 (이용자 입력) | 해당 기능 이용 시 자동 수집 | 핵심 서비스 기능 제공 |
| 캐릭터 이름·상태·진화 이력·도감 | 서비스 이용 중 (자동 생성) | 해당 기능 이용 시 자동 수집 | 펫 캐릭터 기능 제공 |
| 인벤토리·가상재화(두레딧)·구매 로그 | 서비스 이용 중 (자동 생성) | 해당 기능 이용 시 자동 수집 | 게임 기능 제공 |
| 카메라·사진 라이브러리 이미지 | 펫 프로필 사진 설정 시 | 선택 | 캐릭터 프로필 이미지 설정 |

### 2. 수집하지 않는 정보

회사는 다음 정보를 수집하지 않습니다.

- 전화번호, 주소, 성별
- 결제 정보 / 신용카드 정보 (현재 실결제 없음; 가상재화는 TODO 완료를 통해서만 획득)
- 위치 정보(GPS), 연락처(주소록)
- 디바이스 광고 식별자(IDFA, ADID)
- IP 주소, User-Agent (표준 서버 액세스 로그 외 DB 저장 없음)

### 3. 수집 방법

- 앱 내 회원가입 양식을 통한 이용자 직접 입력
- 소셜 로그인(Google, 카카오, Apple)을 통한 OAuth 응답 자동 수신
- 서비스 이용 과정에서의 자동 생성·저장

## 제2조 개인정보의 수집·이용 목적

회사는 수집한 개인정보를 다음 목적으로 이용합니다.

1. **회원 관리**: 회원 가입·탈퇴 처리, 본인 확인, 연령 제한 적용(만 14세 이상 검증), 서비스 부정 이용 방지
2. **서비스 제공**: TODO 관리 기능, 펫 캐릭터 육성 기능, 인벤토리·가상재화(두레딧) 관리
3. **알림 발송**: TODO 마감 알림, 캐릭터 성장·이별 알림 등 서비스 알림 (마케팅 수신 동의 시 이벤트 안내 포함)
4. **인증·보안**: JWT 기반 로그인 상태 유지, 소셜 계정 연동 및 토큰 갱신
5. **캐릭터 이미지 설정**: 이용자가 직접 촬영하거나 선택한 이미지를 프로필로 등록

## 제3조 개인정보의 보유·이용 기간

| 항목 | 보유 기간 | 근거 |
|---|---|---|
| 회원 기본 정보(이메일, 닉네임, 생년월일 등) | 회원 탈퇴 시 즉시 파기 | 이용자 요청 |
| TODO·펫·인벤토리 등 서비스 데이터 | 회원 탈퇴 시 즉시 파기 | 이용자 요청 |
| Refresh Token | 발급 후 14일(만료 시 자동 삭제) | 인증 유효 기간 |
| FCM 디바이스 토큰 | 로그아웃·회원 탈퇴 시 즉시 삭제 | 이용자 요청 |
| 약관 동의 이력 | 회원 탈퇴 시 즉시 파기 | 이용자 요청 |
| 만 14세 미만 가입 시도 시 수집된 데이터 | 확인 즉시 전량 파기 | 법령(개인정보보호법 제22조) |

회사는 전자상거래법 등 법령상 보존 의무(계약 정보, 대금 결제 정보 등)가 현재 해당하지 않습니다(실결제 없음).

## 제4조 개인정보의 파기 절차 및 방법

### 1. 파기 절차

이용자의 개인정보는 목적이 달성된 후 즉시 파기하거나, 보유 기간이 경과한 경우 지체 없이 파기합니다. 회원 탈퇴 시에는 즉시 데이터베이스에서 hard delete(물리적 삭제)를 수행합니다.

### 2. 파기 방법

- **전자적 파일 형태**: 재생 불가능한 기술적 방법으로 영구 삭제(hard delete)
- **소셜 계정 연동 토큰**: Apple Sign-In은 회원 탈퇴 시 Apple Server API를 통해 토큰 revoke 처리

## 제5조 개인정보의 제3자 제공

회사는 이용자의 개인정보를 원칙적으로 외부에 제공하지 않습니다. 다음의 경우를 제외하고는 이용자의 사전 동의 없이 제3자에게 개인정보를 제공하지 않습니다.

- 이용자가 사전에 동의한 경우
- 법령의 규정에 의하거나, 수사 목적으로 법령에 정해진 절차와 방법에 따라 수사기관의 요구가 있는 경우

**현재 광고·마케팅 목적의 외부 제공 및 분석 SDK 활용은 없습니다.**

## 제6조 개인정보 처리의 위탁

회사는 서비스 제공을 위하여 다음과 같이 개인정보 처리 업무를 위탁합니다.

| 수탁업체 | 위탁 업무 내용 | 위탁하는 개인정보 항목 | 위탁 기간 |
|---|---|---|---|
| Google (Firebase Cloud Messaging) | 푸시 알림 발송 | FCM 디바이스 토큰, 알림 내용 | 서비스 이용 기간 |
| Google (Google Sign-In) | 소셜 로그인 인증 | OAuth 액세스 토큰 | 인증 유효 기간 |
| 카카오 | 소셜 로그인 인증 | OAuth 액세스 토큰 | 인증 유효 기간 |
| Apple | 소셜 로그인 인증 및 회원 탈퇴 시 토큰 revoke | OAuth 액세스 토큰 | 인증 유효 기간 |
| AWS (Amazon S3) | 캐릭터·아이템 이미지·애니메이션 파일 저장 | 캐릭터·아이템 미디어 파일 (개인 식별 정보 미포함) | 서비스 이용 기간 |

위탁계약 체결 시 「개인정보보호법」 제26조에 따라 위탁업무 수행 목적 외 개인정보 처리 금지, 기술적·관리적 보호조치, 재위탁 제한, 수탁자에 대한 관리·감독 및 손해배상 등의 내용을 계약서에 명시합니다.

## 제7조 정보주체의 권리·의무 및 행사 방법

이용자(정보주체)는 회사에 대하여 언제든지 다음 각 호의 개인정보 보호 관련 권리를 행사할 수 있습니다.

1. **개인정보 열람 요구**: 앱 내 설정 화면 또는 이메일({{이메일}}) 문의
2. **오류 정정 및 처리정지 요구**: 앱 내 설정 화면 또는 이메일 문의
3. **삭제(탈퇴) 요구**: 앱 내 설정 → 회원 탈퇴 (즉시 hard delete 처리)
4. **비밀번호 변경**: 앱 내 설정 화면 (일반 계정에 한함)
5. **알림 수신 동의 철회**: 앱 내 설정 → 알림 설정 토글

권리 행사는 서면, 전화, 전자우편, 모사전송(FAX) 등을 통하여 할 수 있으며, 회사는 이에 대해 지체 없이 조치합니다. 이용자가 개인정보의 오류 정정 또는 삭제를 요청한 경우 해당 정보의 정정 또는 삭제가 완료될 때까지 당해 개인정보를 이용하거나 제공하지 않습니다.

## 제8조 개인정보의 안전성 확보 조치

회사는 「개인정보보호법」 제29조에 따라 다음과 같은 기술적·관리적 보호 조치를 취하고 있습니다.

| 조치 구분 | 세부 내용 |
|---|---|
| 비밀번호 암호화 | BCrypt 단방향 해시 적용 — 원문 복원 불가 |
| 전송 구간 암호화 | 모든 통신에 HTTPS(TLS) 적용 |
| 인증 체계 | JWT 기반 액세스 토큰(30분) + 리프레시 토큰(14일) |
| 접근 권한 관리 | 운영자 최소 권한 원칙 적용, 불필요한 개인정보 접근 차단 |
| 소셜 토큰 보안 | Apple Sign-In 탈퇴 시 Apple Server API 통해 토큰 revoke 처리 |

## 제11조 14세 미만 아동에 대한 처리 방침

회사는 만 14세 미만 아동의 개인정보 보호를 위하여 다음 정책을 운영합니다.

1. 만 14세 미만 아동은 서비스에 가입할 수 없습니다.
2. 가입 후 온보딩 단계에서 생년월일을 등록할 때 만 14세 미만으로 확인되는 경우, 해당 이용자의 모든 데이터를 즉시 hard delete(물리적 삭제)합니다.
3. 현재 법정대리인 동의 절차는 운영하지 않습니다.
4. 만약 만 14세 미만 아동의 개인정보가 수집된 사실이 확인될 경우, 지체 없이 해당 정보를 파기합니다.
