# 시연 시나리오

> Doitdo 앱 시연 순서에 따른 화면별, 실행별 상세 설명입니다.

---

## 파트 1 — 소셜 로그인 & 홈 진입

### 시연 순서

1. 앱 실행 후 로그인 화면 노출
2. 소셜 로그인 버튼 확인: 카카오 / 구글 / 애플
3. 로그인 진행
4. 홈 화면 진입

### 설명

Doitdo는 일반 로그인 외에도 카카오, 구글, 애플 소셜 로그인을 지원한다.  
로그인 성공 후 사용자는 다마고치 홈 화면으로 진입한다.

### 강조 포인트

- 소셜 로그인 기반의 빠른 진입
- 로그인 후 바로 캐릭터 성장 화면으로 연결되는 구조

---

## 파트 2 — 알 부화 & 이름 짓기

### 시연 순서

1. 홈 화면에서 알 상태 확인
2. 알 터치
3. 금이 가는 애니메이션 확인
4. 부화 완료 후 슬라임 등장
5. 이름 입력 후 확인

### 설명

첫 캐릭터는 알 상태에서 시작한다.  
사용자가 알을 터치하면 부화 애니메이션이 진행되고, 부화한 캐릭터에게 이름을 지어줄 수 있다.

### 강조 포인트

- 앱 첫 사용 경험을 캐릭터 부화로 구성
- 사용자가 캐릭터에 애착을 갖도록 이름 짓기 제공

---

## 파트 3 — 투두 생성 & 경험치·코인

### 시연 순서

1. 하단 + 버튼 클릭
2. 일반 투두 1개 생성: 예시 `"오늘의 할 일"`
3. 생성된 투두 체크 완료
4. 경험치 바 상승 모션 확인
5. 뚜레딧(코인) 획득 UI 확인

### 설명

사용자가 투두를 생성하고 완료하면 캐릭터 경험치와 뚜레딧이 지급된다.  
할 일 완료가 단순 체크로 끝나지 않고 캐릭터 성장과 보상으로 이어진다.

### 강조 포인트

- 투두 완료 → 경험치 상승
- 투두 완료 → 뚜레딧 획득
- 해야 할 일을 게임처럼 지속하게 만드는 보상 구조

---

## 파트 4 — 진화 & 독립

### 사전 준비

시연 전 DB에서 캐릭터 경험치를 99% 상태로 세팅한다.

### 시연 순서

1. 홈 화면에서 경험치 바 99% 상태 확인
2. 투두 1개 완료
3. 경험치 100% 달성
4. 진화 가능 상태 표시 확인
5. 진화 진행
6. 진화 애니메이션 확인
7. 같은 흐름을 반복하여 독립 단계까지 진행

### 설명

캐릭터는 투두 완료로 경험치를 얻고, 일정 경험치에 도달하면 다음 성장 단계로 진화한다.  
최종 성장 이후에는 독립 단계까지 진행할 수 있다.

### 강조 포인트

- 투두 수행이 캐릭터 성장으로 직접 연결됨
- 진화/독립을 통해 장기 사용 동기를 제공

---

## 파트 5 — 도감

### 시연 순서

1. 도감 탭 진입
2. 캐릭터 목록 스크롤
3. 캐릭터 상세 화면 진입
4. 배경 스토리 화면 확인

### 설명

도감에서는 사용자가 획득했거나 성장시킨 캐릭터 목록을 확인할 수 있다.  
캐릭터 상세 화면에서는 성장 단계와 배경 스토리를 확인한다.

### 강조 포인트

- 캐릭터 수집 요소
- 성장 이력을 다시 확인하는 회고 기능
- 캐릭터별 스토리 제공

---

## 파트 6 — 상점

### 사전 준비

시연 전 뚜레딧(코인)을 충분히 충전해둔다.

### 시연 순서

1. 상점 탭 진입
2. 가구 탭 선택
3. 가구 1개 구매
4. 구매한 가구 배치 시연
5. 테마 탭으로 이동
6. 테마 1개 선택
7. 구매 다이얼로그 확인
8. 테마 구매 및 방 적용

### 설명

사용자는 투두 완료로 획득한 뚜레딧을 사용해 가구와 테마를 구매할 수 있다.  
구매한 아이템은 캐릭터가 있는 방에 적용되어 개인화된 공간을 만든다.

### 강조 포인트

- 보상 재화의 사용처 제공
- 방 꾸미기와 테마 변경을 통한 개인화
- 투두 완료 동기 강화

---

## 파트 7 — 캘린더

### 시연 순서

1. 캘린더 탭 진입
2. 일반 투두 생성
3. 기간 투두 생성
4. 캘린더에서 기간 표시 확인
5. 반복 투두 생성
6. 좌우 스와이프로 월 이동
7. 카테고리별 점(dot) 표시 확인
8. 알림 설정 언급

### 설명

캘린더에서는 날짜별 투두를 확인하고, 일반/기간/반복 투두를 관리할 수 있다.  
카테고리별 점 표시로 특정 날짜의 할 일 구성을 빠르게 파악할 수 있다.

### 강조 포인트

- 일반/기간/반복 투두 지원
- 월 단위 일정 확인
- 카테고리별 dot 표시
- 알림 설정을 통한 일정 리마인드

---

## 파트 8 — 설정

### 시연 순서

1. 설정 탭 진입
2. 주요 항목 확인: 계정 / 투두 카테고리 / 알림 / 기본 화면
3. 폰트 변경 시연: G마켓산스 ↔ 프리텐다드
4. 화면 모드 설정 언급
5. 글자 크기 설정 언급

### 설명

설정 화면에서는 계정, 카테고리, 알림, 기본 화면 등 앱 사용 환경을 관리할 수 있다.  
사용자는 폰트, 화면 모드, 글자 크기를 조정해 본인에게 맞는 사용 환경을 만들 수 있다.

### 강조 포인트

- 개인화된 앱 사용 환경
- 카테고리와 알림 관리
- 접근성을 고려한 폰트/글자 크기 설정

---

## 클로징

두잇두는 해야 할 일을 단순히 관리하는 앱이 아닙니다.  
완료할수록 성장하는 캐릭터와 함께, 할 일을 해내는 경험 자체가 즐거워지도록 만들었습니다.
